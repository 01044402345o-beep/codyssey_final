# 키가 저장되는 위치 안내

전체 경로에서 현재사용자 부분을 실제 PC의 사용자 계정 이름으로 바꾸어 탐색기 주소창에 입력하시면 됩니다.
본인 PC의 실제 경로를 찾아 이동하는 방법은 크게 두 가지가 있습니다.

<hr>

- <h3>방법 1. 실행 창으로 바로 열기 (가장 빠름)</h3>

1. 키보드에서 Windows 키 + R을 동시에 눌러 [실행] 창을 엽니다.
2. 입력창에 다음 명령어를 그대로 복사해서 붙여넣고 엔터를 누릅니다.
<br>
```
shell:profile\.opsarchive
```

<p>코드를 사용할 때는 주의가 필요합니다.</p>

3. 이 명령어를 사용하면 현재사용자 이름을 직접 입력하지 않아도 해당 폴더로 즉시 이동합니다.

<hr>

- <h3>방법 2. 파일 탐색기 주소창에 직접 입력하기</h3>

1. 키보드에서 Windows 키 + E를 눌러 파일 탐색기를 엽니다.
2. 탐색기 상단의 주소창(비어 있는 공간)을 마우스로 클릭합니다.
3. 기존 주소를 지우고 아래의 경로를 입력한 뒤 엔터를 누릅니다.
<br>
```
%USERPROFILE%\.opsarchive
```

<p>코드를 사용할 때는 주의가 필요합니다.</p>

> [!NOTE]
> 윈도우에서 %USERPROFILE%은 현재 로그인한 사용자의 폴더 주소를 자동으로 찾아주는 암호 같은 코드입니다.

> [!WARNING]
> ⚠️ 참고: 폴더명 앞에 점(.)이 붙은 폴더는 숨겨져 있는 경우가 많습니다. 
> 만약 위 방법으로 이동했는데 폴더가 비어 있거나 보이지 않는다면, 
> 탐색기 상단 메뉴에서 [보기] -> [표시] -> [숨김 항목]에 체크해 주시면 정상적으로 나타납니다.
