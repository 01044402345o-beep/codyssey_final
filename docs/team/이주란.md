## 1차 테스트에서 발견한 것

- 카카오톡 링크로 열면 **듣기(TTS)와 녹음 기능이 작동하지 않음**
- 사용자가 **다른 브라우저를 여는 방법 자체를 모름**
- 가장 난감했던 장면: 다른 브라우저를 열지 못해 몇 초간 멈췄다가
  앱을 닫고 사용을 포기함
- 참가자 전원 안드로이드, 카카오톡 인앱 브라우저 사용

> "디지털 리터러시가 낮은 사용자는 다른 브라우저 여는 것 자체를
>  생각하지 못해 앱이 잘 작동되지 않는다고 여기는 경우가 있음"

이 지적이 PR #54·#55(인앱 브라우저 감지 + 안내 배너)로 이어졌습니다.

## 2차 확인 결과 (10/17)

같은 참가자들께 수정된 앱을 다시 보냈습니다.

> "다른 브라우저 열기가 상단에 바로 보여 좋았다"

처음에 안 되던 것이 고친 뒤에 됐다는 걸 사용자 쪽에서 확인했습니다.

## 설문 설계 (10/18)

멘토님께서 구글폼 제안을 주신 다음 날 만들어 배포했습니다.
"써보니 어떠셨나요"보다 **"여행 중 무엇이 불편했는가"를 먼저 묻는 구조**로
만들었습니다. 그래야 불편과 저희 기능이 연결되기 때문입니다.

개인정보는 연령대만 받고 이름·연락처는 받지 않았습니다.

현재 14건이 모였고, 그중 8분은 앱을 직접 사용한 뒤 답해주셨습니다.

## 제가 판단한 것
같은 분들께 다시 보낸 이유: 첫 앱 사용자에게 1차 수정후 다시 사용한 후 처음 사용시 불편한 점이 개선되었는 지 확인.

설문 순서 : 연령대에 따른 불편함, 여행 횟수, 가장 필요로 하는 여행 앱에서의 지원 사항들이 각기 다를 것이라 여겨 설문 항목 구성.

테스트에서 주목할 점 : 첫 앱 사용시 불편 사항 개선 여부, 추가로 원하는 기능 적절히 반영되었는지 여부를 중점적으로 살펴봄. 

## 다른 앱과 비교하며 느낀 점

다른 영어회화 앱들보다 실제 갈 장소에서 쓸 수 있으니 더 현실감 있고
연습하고 싶은 동기가 더 생기는 것 같습니다.

저는 스픽도 구독해서 써봤는데 이런 점이 좀 아쉬웠습니다.
막연하게 상황을 상상해서 연습하는 게 많아서 흥미가 떨어졌거든요.

## 어려웠던 것
 사용자들에게 여러 번 사용하고 계속 피드백 요청하는 것이 살짝 부담되었으나 실제로 이런 앱이 나오면 좋겠다는 의견들을 주심.
