# 장소 목록 0건 조사

## 확인 상태

실제 장소 목록이 0건으로 나온 사례는 아직 재현하지 못했습니다.
따라서 발생 단계와 원인은 확인되지 않았습니다.

## 0건이 될 수 있다고 보는 이유

1. **검색어가 도시를 제대로 가리키지 못할 수 있음**
   - 일정 생성 경로는 도시명과 장소 종류를 조합해 Google Places를 검색합니다.
   - 국가나 도시 좌표 정보가 검색에 함께 전달되지 않아, 동명 도시가 있거나 검색 위치가 어긋나면 관련 장소를 찾지 못할 가능성이 있습니다.

2. **장소는 검색됐지만 검증 과정에서 제외될 수 있음**
   - 검색 결과에 장소 ID, 이름, 좌표, 지도 주소 등이 빠졌거나 폐업한 장소라면 화면에 표시되지 않을 수 있습니다.
   - 검색 원본 결과가 있었는지와 제외된 이유를 구분할 정보가 부족하면 결과적으로 0건처럼 보일 수 있습니다.

3. **장소 검색 이후 단계에서 목록이 비어 보일 수 있음**
   - 장소 검색은 성공했지만 일정 생성이나 후속 검증이 실패하면, 사용자에게는 추천 목록이 없는 것처럼 보일 가능성이 있습니다.
   - 여행 조사 경로는 여러 자료 공급원과 캐시를 사용하므로, 한 공급원의 실패인지 전체 결과가 없는 것인지 구분해야 합니다.

## 재현 시 가설별 확인 항목

- 도시명·국가·좌표와 장소 종류가 검색 요청에 어떻게 전달됐는지 확인합니다.
- 공급자 원본 결과 수, 검증 통과 수, 제외 수와 제외 이유를 비교합니다.
- 장소 검색 결과와 최종 화면·일정 결과를 비교해 어느 단계에서 비었는지 확인합니다.
- 사용한 기능, 요청 시각, 배포 버전, 오류 상태와 실제 검색 질의어를 함께 기록합니다.

## 복구 제안

- 정상 검색 결과 0건, 공급자 장애, 검증 후 0건, 후속 일정 생성 실패를 서로 다른 상태로 기록합니다.
- 일시적 장애나 갑작스러운 결과 감소로 기존 정상 결과가 사라지지 않도록 이전 결과의 보존·복구 방안을 검토합니다.
- 실제 실패 사례를 확보한 뒤 같은 도시와 장소 종류로 현재 공급원과 대체 서비스를 비교합니다.
