## 6. 원문 기록 — 이주란 님 4명 (팀 저장소 `main` `86b2d00`, 10/11, 루트 파일 `Review of App`)

> 원문 그대로 옮김. 해석·원인은 아래 표의 별도 칸에 둔다. 측정(과업 성공률·점수)이 아닌 관찰 메모이며, 기기·OS·브라우저·진행 방식은 원문에 없다.
> 아래 P1~P4 는 이 4명의 번호이며 위 1절 표의 P1~P4 와 같은 사람이다.

- P1 : 카톡링크로 받아 사용해보니 일부 브라우저에서는 일부 기능이 지원되지 않음.(듣기 , 녹음 기능)
- P2 : 디지털 리터러시가 낮은 사용자는 다른 브라우저 여는 것 자체를 생각하지 못해 앱이 잘 작동되지 않는다 여기는 경우가 있음.(3~5초 멈춤, 또는 앱을 닫아버림)
- P3 : 끝까지 사용해보는 경우 speaking 속도 조절이나 듣고 말해보기, 틀린 발음 교정, 반복 연습 가능한 점 등에 만족도 높음.
- P4 : 여행을 앞두고 기간 별, 장소를 특정하여 연습할 수 있음을 특히 장점으로 언급함.

| 항목 | 상태 |
|---|---|
| P1·P2 원인 | **확정(스크린샷 기준)** — 4명 모두 안드로이드. 카카오톡 앱 안 브라우저에서는 **듣기(음성 재생)만** 안 됨("이 브라우저는 듣기를 지원하지 않아요"), **말해보기 버튼은 보였고 녹음 가능**. Chrome 으로 열면 듣기·말하기 모두 정상 |
| 기억과 스크린샷 차이 | 한 분은 "마이크 버튼이 안 보였다"고 기억했으나 5:35 스크린샷에는 말해보기 버튼이 있다. 이 문서는 스크린샷을 기준으로 한다 |
| 대응 | 안내 배너 문구를 듣기로 좁히고 카톡 자체 메뉴 안내로 변경: "카카오톡에서는 '듣기'(음성 재생)가 안 돼요. 오른쪽 아래 ⋮ → '다른 브라우저로 열기'를 눌러 주세요. 말하기와 카드 학습은 여기서도 돼요." (`fix/dup-swipe`). 되는 것을 함께 알리는 것은 P2(앱을 닫아 버림) 대응 |
| 재테스트 | 배포 후 같은 분들께 1회 더 — "저번엔 안 됐는데 이번엔 됐다" 확인용 |
| P3·P4 | 인용 전 원문(위)과 대조할 것 |
