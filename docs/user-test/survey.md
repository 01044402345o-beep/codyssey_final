# 사후 설문 (참가자용, 약 5분)

Google Forms 등에 그대로 옮겨 쓸 수 있게 작성했다. **이름·연락처는 받지 않는다.** 참가자 번호(P1, P2…)만 진행자가 입력한다.

## A. 배경 (선택형)

1. 참가자 번호: ____ (진행자 입력)
2. 영어 말하기 수준(스스로 생각하기에): ① 거의 못 함 ② 기초 ③ 초급 ④ 중급 이상
3. 최근 1년 안에 해외여행을 했거나 예정이 있나요? ① 예 ② 아니요
4. 사용한 기기: ① 휴대폰(아이폰) ② 휴대폰(안드로이드) ③ PC
