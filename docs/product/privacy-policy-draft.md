## 1. 처리하는 개인정보와 목적

| 구분 | 항목 | 목적 | 언제 |
|---|---|---|---|
| 계정 | Firebase 사용자 ID(uid), 이메일, 이름(표시 이름), 로그인 방식(Google·이메일) | 로그인, 다른 기기에서 학습 이어 하기 | 로그인할 때(로그인 없이 시작하면 처리하지 않음) |
| 학습 기록 | 완료·미리 학습한 날짜, 날짜별 학습 활동 수, 보던 화면·카드 위치, 복습 목록(상황 이름과 문장), 말하기 동의 여부·시각 | 진도 유지, 복습, 연속 학습 표시 | 로그인한 사용자: 계정에 저장 · 로그인하지 않은 사용자: 이 브라우저에만 저장 |
| 여행 입력 | 나라, 도시(최대 5곳)와 체류 날짜, 학습 시작일 | 여행에 맞춘 학습 계획 | 같은 방식(계정 또는 브라우저) |
| 말하기 녹음 | 말해보기·대화하기에서 녹음한 음성(최대 15초), 그 음성의 전사(들린 문장) | 말한 문장과 목표 문장 비교, 고칠 점 안내 | 사용자가 **말하기 동의**를 한 뒤 녹음할 때만 |
| 실시간 통역 음성 | 통역을 켠 동안 마이크로 들어온 소리(한 번에 최대 3분), 그 소리의 원문·번역 자막 | 내 말(한국어)과 상대 말(영어)을 서로의 언어로 바꿔 보여 주고 들려주기 | **로그인한 계정**이 통역 동의를 한 뒤 '통역 시작'을 누른 동안만(익명·로그인 없이 시작은 쓸 수 없음) |
| 접속 기록 | IP 주소(요청 제한), 서버 로그 | 남용 방지, 장애 대응 | 모든 요청 |
| 탈퇴 실패 기록 | 탈퇴가 끝나지 않았을 때의 상태(위 계정·학습 기록이 포함될 수 있음, 자격증명은 제거), uid 해시 | 탈퇴를 끝까지 처리했음을 입증하고 오류를 고치기 위해 | 탈퇴가 실패했을 때만 |

처리하지 **않는** 것: 음성 원본 저장, 화자 식별(목소리로 사람을 알아보는 처리), 위치 정보, 연락처, 결제 정보.

## 2. 보유 기간과 파기

| 항목 | 보유 기간 | 파기 |
|---|---|---|
| 계정·학습 기록·여행 입력(로그인 사용자) | 탈퇴할 때까지 | 탈퇴 시 계정 문서(`users/{uid}`)와 로그인 계정을 삭제 |
| 같은 기록(로그인하지 않은 사용자) | 사용자가 지울 때까지(이 브라우저 저장소) | '처음 상태로'·브라우저 데이터 삭제 |
| 말하기 녹음 | **저장하지 않음** — 채점 요청을 처리하는 동안 서버 메모리에만 있다. 화면의 '내 발음 듣기'용 녹음은 그 탭에만 있고 카드를 넘기면 지운다 | 요청이 끝나면 사라짐 |
| 실시간 통역 음성·자막 | **저장하지 않음** — 서버는 받은 소리를 제공자에게 바로 넘기고 남기지 않는다. 자막은 그 화면에만 있고 통역을 끝내거나 화면을 옮기면 사라진다 | 통역이 끝나면 사라짐(제공자 쪽 보관은 3절) |
| 전사·채점 결과 | 화면에 보여 줄 뿐 서버에 저장하지 않음. 사용자가 복습 목록에 저장한 문장만 학습 기록으로 남음 | 위 학습 기록과 같음 |
| 탈퇴 실패 기록 | **90일**(Firestore TTL `expire_at`) | 기간이 지나면 자동 삭제 |
| 접속 로그 | **[확인 필요]** 호스팅(Render) 로그 보관 기간 | **[확인 필요]** |

## 3. 처리 위탁과 국외 이전

## 4. 이용 연령

**[팀 결정·법률 확인]** Gemini API 약관은 **만 18세 이상**만 허용한다(조사 04 §1 #6). 만 14세 미만은 법정대리인 동의가 필요하다. 제안: 말하기·AI 기능에 "만 18세 이상" 자기 확인을 둔다.

## 5. 이용자의 권리

- **열람·내려받기:** 로그인한 사용자의 계정 기록은 앱 홈의 'AI · 개인정보' 카드에서 확인할 수 있다. 전체 내려받기 기능은 **[팀 결정]**(현재 없음).
- **정정:** 여행 설정 수정, 복습 목록 삭제를 앱에서 할 수 있다.
- **동의 철회:** 홈의 '동의 철회' — 철회하면 동의와 복습 목록을 지운다. 실시간 통역 동의는 홈 'AI · 개인정보' 카드의 '통역 동의 철회'로 따로 철회한다(다음 통역 때 다시 묻는다).
- **삭제(탈퇴):** 홈의 '탈퇴하기' — 계정 문서와 로그인 계정을 지운다. 탈퇴가 실패하면 실패 기록이 90일 남는다(2절).

## 6. 브라우저 저장소(쿠키 아님)

로그인하지 않은 사용자의 기록과 화면 설정을 이 브라우저의 `localStorage` 에 둔다: 진도(`cd_session`), 복습 목록(`cd_weak`), 말하기 동의(`cd_consent`), 실시간 통역 동의(`cd_interp_consent`, 동의 문구 버전과 시각), 여행 입력, 화면 모드(`cd_theme`). 로그인하면 같은 항목이 계정별 칸(`…:uid`)에 나뉜다. 광고·분석 쿠키와 분석 스크립트는 쓰지 않는다(2026-10-20 `mockup/` 확인: 외부에서 불러오는 것은 글꼴 — Google Fonts·jsDelivr Pretendard — 과 로그인용 Firebase SDK(`www.gstatic.com/firebasejs`)뿐). 글꼴·SDK 를 불러올 때 브라우저가 그 서버에 IP 주소를 보낸다.

## 7. 안전성 확보 조치

- 전송 구간 암호화(HTTPS).
- 계정 기록은 로그인 토큰을 확인한 뒤 **그 사용자 uid 의 문서만** 읽고 쓴다. 서버 저장 항목은 화이트리스트로 검증한다(모르는 항목은 거절).
- 녹음 원본을 저장하지 않는다. 말소리가 없는 녹음은 외부 전사 업체로 보내지 않는다.
- 실시간 통역: 유료 제공자로 가는 연결은 로그인 토큰을 확인한 계정만 열 수 있고(익명 거절), 계정·IP 마다 시작 횟수를 제한하며, 한 번에 최대 3분이 지나면 서버가 끊는다. 통역 키는 서버에만 둔다.
- AI 키·서비스 계정 키는 서버 환경변수에만 둔다(브라우저에 내려보내지 않음).
- 탈퇴 실패 기록은 관리자 공개키로 **봉인(암호화)** 해 저장하고, 자격증명은 지운 뒤 봉인한다. 앱 서버는 복호화할 수 없다.
- 요청 수 제한(IP 기준).

## 9. 변경

이 처리방침을 바꾸면 앱에 게시하고 시행일을 적는다. 말하기 동의 문구의 버전(`consent.version`), 실시간 통역 동의 문구의 버전(`INTERP_CONSENT_VERSION`)과 맞춘다. 통역 동의 문구가 바뀌면 버전을 올려 다시 묻는다.
