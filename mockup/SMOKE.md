# 시연 전 수동 스모크 체크리스트

자동 테스트(`cd mockup && node --test`)는 응답 분기·저장 조건 같은 **코드 규칙**만 확인합니다.
실제 AI 생성·마이크·배포 환경은 아래를 **배포 URL에서 직접** 확인해야 합니다. (현재 상태: 연동 구현 완료, 실환경 검증 대기)

시연 점검 완료 기준 = `/health` 호출이 아니라 **실제 생성 1회 + 말하기 1회 확인**.

## 준비
- [ ] `main` 머지 후 Render Blueprint 배포, 환경변수 `GEMINI_API_KEY` 입력
- [ ] `<URL>/health` → `has_api_key: true`, `categories: ["restaurant"]` (콜드스타트 깨우기용, 이것만으로는 완료가 아님)

## 실제 생성 (키 있는 서버)
- [ ] 여행 입력 → 보고서 → 장소 확정 → 문장 생성이 끝까지 진행 (첫 요청은 시간이 걸릴 수 있음 안내가 뜰 수 있음)
- [ ] 학습 카드에 맛집 문장이 **"AI 생성"** 배지로 보인다 (키 없는 서버면 "샘플"만 떠야 정상)
- [ ] 서버를 끄거나 `?api=http://127.0.0.1:1` 로 열면 같은 흐름이 로컬 템플릿으로 끝까지 진행된다

## 말하기 (실제 마이크)
- [ ] 카드 뒷면 "🎤 말해보기" → 녹음 → "■ 녹음 끝내기" → 점수·tip 표시
- [ ] 점수 70 미만이고 들린 문장이 있으면 "복습 목록에 자동 저장했어요(점수 기반 임시 규칙)", 70 이상이면 저장 안 됨
- [ ] 점수가 안 오는 경우: 자동 저장하지 않고 "이 상황을 복습 목록에 저장" 버튼이 뜬다(누르면 저장). 목표 단어 일치율은 참고로만 표시. 무음·인식 실패(heard 없음)는 점수가 있어도 버튼도 자동 저장도 없음 (임계값 70은 임시 규칙)
- [ ] 실제 Gemini로 score 빈도를 센다: `python backend/scripts/measure_score_rate.py --base <URL> --audio <파일> --target "<문장>" --label good|bad|silent --n 10` (조건 3가지를 각각 실행)
- [ ] 녹음 중 다음 카드로 이동하면 녹음이 취소되고 업로드되지 않는다 (마이크 표시등 꺼짐)
- [ ] 마이크 권한을 거부해도 카드 학습은 계속된다

## 기억 (재생성 시 복습)
- [ ] 데모 패널 "데모 학습 기록 불러오기" → 새 여행 생성 → AI 문장에 **"복습 목록 상황 · 데모 학습 기록"** 배지
- [ ] 실제로 말하기에서 저장된 복습 상황은 "데모" 표기 없이 같은 배지가 뜬다
- [ ] 키 없는 서버/샘플 응답에서는 복습 배지가 뜨지 않는다 (개인화가 일어나지 않았으므로)
